本地构建工作流

build_local.py 是单个版本的本地入口。它支持清理、依赖检查、静态服务、端口设置、跳过 PDF、禁止自动安装和分支检查等常用工作流。

参数

作用

–clean

构建前清理旧 HTML 输出

–serve

构建后启动静态服务器

–port 8000

指定静态服务器端口

–no-pdf

跳过 XeLaTeX，专注网页反馈

–check

检查依赖和构建环境

–no-auto-install

只检查，不安装 Python 或 PDF 依赖

–check-branch

验证当前分支是否符合版本配置

构建完成后，检查首页跳转、左右侧栏、搜索、深层链接、语言切换和静态图片。不要只看首页：目录首页、第三层页面和不存在翻译的回退页面最容易暴露路径问题。

桌面端还应确认页面按左侧全局目录、中间正文、右侧文章大纲排列；调整窗口宽度时正文不突然跳宽，空间不足时大纲才移动到正文下方。文章大纲中的 h2/h3 应保持嵌套缩进，点击标题后平滑滚动并更新高亮；在左侧切换文章后，之前展开的目录路径应保持。

使用 --serve 时脚本以前台运行；结束服务可在终端按 Ctrl+C。若端口已被占用，请使用 --port 指定另一个未使用端口。
