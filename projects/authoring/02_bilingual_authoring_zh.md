# 双语编写与语言切换

双语不是把同一页面混合两种语言。模板分别构建中文和英文源文件，各自拥有导航、搜索索引和静态资源。只有检测到两种语言的根 README 时，页面才显示切换控件。

## 对应页规则

| 当前页面 | 目标语言页面存在 | 目标页面不存在 |
| --- | --- | --- |
| setup_zh.md | 跳转 setup.md | 跳转英文首页 |
| setup.md | 跳转 setup_zh.md | 跳转中文首页 |

这项回退策略允许团队渐进翻译，不会因为某一篇英文尚未完成而导致切换按钮失效。完成翻译时只需补齐同基础名的文件，不需要修改前端逻辑。

## 译文质量门槛

接口名、命令、文件路径、配置字段和值保持原样；解释性文字按目标读者重写，不逐词翻译。发布前在两种语言下分别搜索关键术语，并从多个深层页面测试语言切换，确保链接不是只在首页正确。
