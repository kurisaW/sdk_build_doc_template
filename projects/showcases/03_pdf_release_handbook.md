# Showcase: Archivable PDF Release Handbook

Field delivery, customer acceptance, and offline training need a document that remains stable without a website. Pagination, fonts, bookmarks, and code readability are delivery requirements rather than decoration.

| Content type | What to verify |
| --- | --- |
| Long bilingual headings | Chapters, bookmarks, and headers remain readable |
| Wide tables | Stay within the page and retain clear headers across pages |
| Code blocks and inline code | Monospace font is correct and long commands do not obscure prose |
| PNG, JPG, and WebP | Orientation, dimensions, and clarity remain stable |
| Deep hierarchy | Contents, bookmarks, and chapter breaks remain navigable |

PDF_STYLE defaults to web and also supports thesis, graduate, and academic. Install the exact config.yaml font names in CI so cloud and local typography agree. The result is a validated file, not a web screenshot; download controls reflect the PDFs that were actually generated.
