# 示例：可归档的 PDF 发布手册

## 场景

现场交付、客户验收和离线培训都需要一个不依赖网页的稳定文档。此时 PDF 的分页、字体、书签和代码可读性属于交付要求，不是视觉装饰。

## 建议的内容压力测试

| 内容类型 | 应验证的现象 |
| --- | --- |
| 长标题与中英文混排 | 章节层级、书签和页眉不乱码 |
| 宽表格 | 不超出页面，换页后表头仍清晰 |
| 代码块与行内代码 | 等宽字体正确，长命令不遮挡正文 |
| PNG、JPG、WebP | 方向、尺寸和清晰度稳定 |
| 多层目录 | 目录、书签和章节分页可跳转 |

通过 PDF_STYLE=web 默认生成产品文档；需要论文或归档预览时，可设置 PDF_STYLE=thesis、graduate 或 academic。无论哪种样式，都应在 CI 中安装 config.yaml 指定的同名字体，确保本地和云端排版一致。

最终 PDF 不是网页截图，而是经过有效性校验的文件。构建脚本会检查文件头和最小大小，下载入口根据实际生成的中文或英文文件自动呈现。
