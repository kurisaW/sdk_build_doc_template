# Showcases

These are not isolated feature demos. Each maps a realistic repository to a content structure, configuration choice, build command, and observable release result.

| Scenario | Best for | What it validates |
| --- | --- | --- |
| [Embedded SDK Guide](01_embedded_sdk_guide.md) | SDK teams with installation, API, and debug documentation | Recursive tree, bilingual content, rich Markdown |
| [BSP and Driver Catalog](02_bsp_driver_catalog.md) | Teams with boards and several sample projects | Strict catalog, categories, and asset allowlists |
| [Archivable PDF Handbook](03_pdf_release_handbook.md) | Customer, field, or audit deliveries | XeLaTeX, fonts, layouts, bookmarks, and images |
| [Versioned GitHub Pages](04_versioned_pages_release.md) | Open-source projects with latest and stable releases | Worktrees, artifacts, PR gates, and Pages |

Each page can be linked from a project README to demonstrate that the template is not an empty scaffold but engineering infrastructure for a real delivery workflow.
